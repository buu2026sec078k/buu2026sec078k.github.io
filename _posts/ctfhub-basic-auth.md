# 基础认证
**题目来源**: CTFHub
**题型**: Web
**难度**: 简单

## 解题思路
1. 访问靶场页面直接弹出浏览器自带的账号密码弹窗，属于 HTTP Basic Auth 基础认证，无前端表单，是服务端认证机制。
2. 抓包观察请求，请求头里存在 `Authorization: Basic xxx`，内容是 `用户名:密码` 的base64编码。
3. 使用Burp Intruder模块对基础认证进行弱口令爆破。
4. 爆破得到正确账号密码，填入弹窗通过认证，页面返回flag。

## 关键操作
> HTTP基础认证只是Base64编码，不是加密，抓包找到Authorization头，直接在Burp里针对该认证头爆破。

## 总结
本题考察HTTP Basic基础认证的识别与爆破。基础认证仅做base64编码，安全性很低，很适合用弱口令字典爆破，是Web入门常见题型。
