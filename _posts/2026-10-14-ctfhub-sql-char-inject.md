# 字符型注入
**题目来源**: CTFHub
**题型**: Web
**难度**: 简单

## 解题思路
1. 判断注入点：传入参数 `id=1'` 页面出现SQL报错，说明参数被单引号包裹，存在字符型SQL注入漏洞。
2. 测列数：`id=1' order by 2--+` 页面正常，`id=1' order by 3--+` 页面报错，推出查询语句一共 2 列。
3. 找回显位：使用 `id=-1' union select 1,2--+`，成功让页面显示出我们控制的数字，确定回显位置。
4. 查库名：将回显位替换为 `database()`，获取当前数据库名。
5. 查表名：使用 `group_concat(table_name)` 替换回显位，从 information_schema.tables 中查出表名 flag,news。
6. 最终掏数据：替换回显位为 flag，查询flag表中的数据拿到最终结果。

## 关键操作
> 字符型注入需要单引号闭合；先使用单引号测试确认注入；order by判断字段数量；union select联合查询依次获取库、表、字段数据。
