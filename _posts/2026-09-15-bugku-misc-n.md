# Bugku CTF Misc — 这是一张单纯的图片

## 题目描述
题目只给了一张图片，提示是 key{}。

## 解题过程
1. 下载图片后，首先尝试用 VS Code 搜索文本、查看属性，均无结果。
2. 使用 Python 脚本读取图片二进制数据，正则搜索 flag，也没有结果。
3. 打开在线十六进制编辑器（hexed.it）查看图片，拉到文件最底部，发现一串以 `&#` 开头、`;` 结尾的 HTML 实体编码。
4. 编写 Python 脚本，使用正则提取并解码这些 HTML 实体编码。
5. 得到明文：`key{you are right}`。

## 陷阱提醒
题目描述里明确要求是 `key{}`，而不是惯例的 `flag{}`，需要注意格式。

## 最终 Flag
`key{you are right}`

## 学习心得
图片隐写不只会藏在文件属性里，更常见的是追加在文件末尾，并用各种编码（如 HTML 实体、十六进制）伪装。
十六进制查看工具是杂项题的常备工具；做题时也要仔细留意题目描述里的格式要求。
