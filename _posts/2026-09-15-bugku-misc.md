# Bugku CTF Misc

## 题目描述
题目只给了一张图片，提示是 key{}。

## 解题过程
1. 下载图片后，首先尝试用 VS Code 搜索文本、查看属性，均无果。
2. 使用 Python 脚本读取图片二进制数据，正则搜索 flag 也没有结果。
3. 换用在线十六进制编辑器（hexed.it）打开图片，拉到文件最底部，发现了一长串以 `&#` 开头、以 `;` 结尾的 HTML 实体编码。
4. 编写 Python 脚本，使用正则提取并解码这些 HTML 实体。
5. 得到明文：`key{you are right}`。
6. **陷阱提醒**：题目描述里明确要求是 `key{}`，而不是惯例的 `flag{}`，侥幸发现并避开了格式错误。

## 最终 Flag
`key{you are right}`

## 学习心得
图片隐写不仅会藏在文件属性中，更常见的是追加在文件末尾，并使用各种编码（如 HTML 实体、Base64、十六进制）进行伪装。十六进制查看工具是 CTF 杂项题的必备武器。同时，做题时一定要仔细阅读题目“描述”里的格式要求。
